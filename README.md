# Bark Push Icons

Icons for Hermes/Studio Bark task-completion push notifications.
Served via jsDelivr: `https://cdn.jsdelivr.net/gh/zorro-cell/bark-icons@main/<file>`

| File | Used for |
|---|---|
| codex.png | Codex 任务 |
| claude.png | Claude / Claude Code 任务 |
| antigravity.png | 反重力 任务 |
| ekko.png | EKKO 任务 |
| grok.png | Grok 任务 |
| zcode.png | Z Code 任务 |
| default.jpeg | 默认/共用（Hermes、Pi 等未映射 agent）|

PNG 原件提取自本机 App 的 .icns（sips 转 1024x1024）；default.jpeg 为哥哥原头像图。
